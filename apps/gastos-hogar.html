Llibre de Gastos

Conecta tu proyecto de Supabase para guardar el histórico de la cuenta conjunta (y más adelante, la personal).

¿Aún no tienes el proyecto creado?

1. Crea un proyecto gratis en supabase.com.
2. Abre el SQL Editor y pega esto:

create table expenses (
  id uuid primary key default gen_random_uuid(),
  fecha date not null,
  importe numeric not null,
  concepto text,
  categoria text,
  cuenta text not null default 'Conjunta',
  origen text default 'manual',
  hash text unique not null,
  created_at timestamptz default now()
);

create table categories (
  nombre text primary key,
  color text,
  orden int
);

alter table expenses disable row level security;
alter table categories disable row level security;
grant usage on schema public to anon;
grant all on expenses to anon;
grant all on categories to anon;

3. Ve a Project Settings → API y copia la Project URL y la clave anon public aquí arriba.
