Llibre de Despeses

Connecta el teu projecte de Supabase per desar l'històric del compte conjunt (i més endavant, el personal).

Encara no tens el projecte creat?

1. Crea un projecte gratuït a supabase.com.
2. Obre l'SQL Editor i enganxa això:

create table expenses (
  id uuid primary key default gen_random_uuid(),
  fecha date not null,
  importe numeric not null,
  concepto text,
  categoria text,
  cuenta text not null default 'Conjunta',
  origen text default 'manual',
  hash text unique not null,
  created_at timestamptz default now()
);

create table categories (
  nombre text primary key,
  color text,
  orden int
);

alter table expenses disable row level security;
alter table categories disable row level security;
grant usage on schema public to anon;
grant all on expenses to anon;
grant all on categories to anon;

3. Vés a Project Settings → API i copia la Project URL i la clau anon public aquí dalt.
